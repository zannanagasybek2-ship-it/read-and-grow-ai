READ AND GROW AI — GITHUB + VERCEL

Бұл — интернетке орналастыруға дайын код. ZIP файлын ашу сайтты автоматты түрде жарияламайды.
Бұрынғы file:/// сілтемесі телефонға жіберуге жарамайды. Жариялағаннан кейін https://...vercel.app сілтемесін пайдаланыңыз.

НЕ ДАЙЫН?
• Бақылаушы жеке 4 таңбалы кодпен кіреді.
• Оқушы QR-ды сканерлеп, атын/лақап атын және сыныбын жазады. Email қажет емес.
• Оқылған кітап, тапсырма ұпайы, марапат, жазбаша пікір ортақ дерекқорда сақталады.
• Бақылаушы барлық оқушының жұмысын көріп, пікір жаза алады.
• Видео/аудио жүктеу: 20 МБ-қа дейін. Материалды тек иесі мен бақылаушы көреді.
• 20 ағылшынша бейімделген шығарма: әрқайсысы 6 оқу беті, 20 сөз және тапсырмалар.
Бұл түпнұсқа кітаптардың толық нұсқасы емес, оқу мақсатындағы ықшам қайта әңгімелеу.

1. ZIP-ТІ АШУ
Файлға оң жақ батырма → «Извлечь все» → «Извлечь».
Read_and_Grow_AI_Vercel_GitHub ішіндегі START_HERE_KZ.txt файлы — осы нұсқаулық.

2. ДЕРЕКҚОРДЫ ДАЙЫНДАУ (SUPABASE)
Браузердің жоғары мекенжай жолағына https://supabase.com/dashboard жазыңыз.
Тіркеліңіз → New project. Дерекқор паролін өзіңіз орнатып, сақтаңыз.
Жоба дайын болған соң SQL Editor → New query.
Жүктелген папкадағы supabase/setup.sql файлын Блокнотпен ашыңыз.
Ішіндегі мәтіннің бәрін көшіріп, SQL Editor терезесіне қойыңыз → Run.
Жоба Settings / API немесе Connect бөлімінен Project URL және серверге арналған service_role кілтін алыңыз.
service_role — құпия кілт. Оны GitHub кодының ішіне, QR-ға немесе чатқа салмаңыз.
Ашық anon / publishable кілті бұл сервер баптауы үшін жарамайды.

3. GITHUB-ҚА КОДТЫ САЛУ
https://github.com → кіріңіз → New repository.
Аты: read-and-grow-ai. Private таңдауға болады → Create repository.
«uploading an existing file» немесе Add file → Upload files.
Жүктелген папканың ІШІНДЕГІ web, scripts, api, lib, supabase папкаларын,
package.json, vercel.json және нұсқаулықтарды бірге жүктеңіз.
package.json репозиторийдің ең үстіңгі деңгейінде тұруы керек.
Дайын ZIP-ті жалғыз файл етіп жүктемеңіз. .env немесе құпия кілттерді жүктемеңіз.
Commit changes басыңыз.

4. VERCEL-ГЕ ЖАРИЯЛАУ
https://vercel.com → GitHub арқылы кіріңіз → Add New → Project.
read-and-grow-ai репозиторийін Import таңдаңыз.
Framework Preset: Other. Build Command: npm run build. Output Directory: public.
Environment Variables бөліміне үш мән қосыңыз:

SUPABASE_URL = өз Project URL мекенжайыңыз
SUPABASE_SERVICE_ROLE_KEY = өз құпия service_role кілтіңіз
SUPERVISOR_PIN = өзіңіз таңдаған ДӘЛ 4 цифр

Мысалы, PIN ішінде әріп не бос орын болмасын. Кодты оқушыға бермеңіз.
Қосымша SESSION_SECRET міндетті емес. Қоссаңыз, кездейсоқ 32+ таңбалы мән орнатыңыз.
Deploy басыңыз. Дайын болған соң Visit батырмасын басыңыз.
Жарияланған https://...vercel.app сілтемесін сақтаңыз.
Егер баптауларды кейін өзгертсеңіз, Deployments → Redeploy қажет.

5. БАҚЫЛАУШЫ БОЛЫП КІРУ
Сайтта «Supervisor · Бақылаушы» басыңыз.
SUPERVISOR_PIN ретінде өзіңіз орнатқан 4 цифрды енгізіңіз → «Кіру».
«Show classroom QR» басыңыз. QR-ды оқушыға көрсетіңіз.
QR ішінде сынып коды болады. Жеке бақылаушы PIN-і болмайды.

6. ОҚУШЫ БОЛЫП СЫНАУ
Телефон камерасымен QR-ды сканерлеңіз.
Атын/лақап атын және сыныбын жазыңыз → Join classroom.
Шығарма оқып, тапсырма орындаңыз.
Бақылаушы кабинетінде «Refresh results» басып, баллын тексеріңіз.
View work → жазбаша жұмыс/видео → пікір жазу → Save feedback.
Оқушы Sync my work басқанда бақылаушы пікірін алады.

МАҢЫЗДЫ
Оқушыны осы браузердегі қорғалған cookie таниды. Басқа телефон немесе жасырын режим — жаңа оқушы.
Браузер деректерін өшірмес бұрын My journey / reading passport арқылы нәтижені экспорттаңыз.
Бұрынғы компьютердегі нәтижелер автоматты көшпейді: JSON экспорттап, жаңа оқушы болып кіргеннен кейін импорттаңыз.
Бұл оқу барысын бақылауға арналған. Ұпай ресми емтихан бағасы емес.
Код тегін. Supabase пен Vercel қызметтерінде тариф шектеулері бар; шексіз тегін сақтау уәдесі берілмейді.
Осы нұсқада 200 оқушы, 50 сақталған медиафайл, әр файл 20 МБ-қа дейін шектеу қойылған.
Балалардың видеосын орналастыруда мектептің келісім тәртібін қолданыңыз; лақап ат жеткілікті.
Нақты ЖИ чаты немесе видеоны ЖИ арқылы автоматты бағалау қосылмаған.

АШЫЛМАСА
«Платформаны баптау қажет» → Vercel Environment Variables үш мәнін тексеріп, Redeploy.
Кіру/сақтау қатесі → supabase/setup.sql толық орындалғанын және Project URL/кілтті тексеріңіз.
Код қабылдамаса → SUPERVISOR_PIN дәл 4 цифр ма? Көп қате әрекеттен кейін 15 минут күтіңіз.
Телефонда file:/// не localhost ашылмайды → жарияланған https://...vercel.app сілтемесін пайдаланыңыз.
